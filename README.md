# Customer Segmentation Analysis

## Project Overview
This project performs Customer Segmentation using Python and K-Means Clustering.

The analysis helps identify different customer groups based on:
- Revenue
- Order Frequency
- Purchasing Behavior

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Steps
1. Data Cleaning
2. Exploratory Data Analysis
3. Feature Selection
4. K-Means Clustering
5. Data Visualization
6. Business Insights

## Output
Customer groups were classified into:
- Premium Customers
- Regular Customers
- Low-value Customers
